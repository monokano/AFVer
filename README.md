# AFVer — Adobe File Version

Illustrator・Photoshop・InDesignのファイルをブラウザのウィンドウにドロップすると、**作成バージョン**を判定して一覧表示するWebアプリです。フォルダのドロップにも対応しています。

- **単一HTMLで完結** — `index.html` の1ファイルだけ。
- **外部ライブラリ不使用・完全オフライン** — ファイルはサーバーに送信されません。すべてブラウザ内で解析します。
- **拡張子に依存しない判定** — ファイルの中身からAdobe形式を自動判別します。

## 使い方

1. **https://monokano.github.io/AFVer/** をブラウザで開きます。<br>ローカルで使う場合は  `index.html` を直接開いてもかまいません。
2. ファイルまたはフォルダをウィンドウにドラッグ＆ドロップします。
   - 「開く…」メニューからファイル選択・フォルダ選択も可能です。
3. 各ファイルの作成バージョンが一覧表示されます。フォルダを含む場合はFinder風の階層ツリーで表示されます。

> **Tip:** ローカルで `file://`（HTMLをダブルクリック）で開くと、Chrome/Edgeではフォルダのドラッグ＆ドロップが制限されます。その場合は「フォルダを選択」メニューを使うか、Safariで開いてください。HTTPサーバ経由（`http(s)://`）で開けば制限はありません。

## 対応形式

| 系統 | 形式 |
| --- | --- |
| Illustrator 系 | `.ai` `.ait` `.eps` `.pdf`  |
| Photoshop 系 | `.psd` `.psb` `.eps` `.pdf` |
| InDesign 系 | `.indd` `.indt` `.indb` `.indl` `.idml` |

判定ロジックは、移植元のmacOSアプリ（File Ver Ai / File Ver Id）のロジックを忠実に移植したものです。

## 機能

- **階層ツリー表示** — フォルダ構造をFinder風に表示。展開したフォルダの直下だけを解析する遅延ロード方式で、無駄な解析を行いません。
- **全て展開 / 全て折りたたむ** — 全フォルダを一括で展開・解析、またはトップに戻します。
- **印刷 / PDF** — 今の展開状態をそのままブラウザの印刷機能で出力できます（「PDFとして保存」でPDF化）。全件を出力したいときは先に「全て展開」してください。
- **ライト / ダークモード対応** — OSの外観設定に追従します。

## 動作環境

- モダンブラウザ（Chrome / Safari / Edge など）。
- ZIP/zlibの展開にブラウザ標準の `DecompressionStream` を使用するため、これに対応したブラウザが必要です。

## 設計について

ブラウザや対象ファイルの仕様により、いくつかの制限があります。

- **「Finderで表示」は非対応** — ブラウザは絶対パスを返さず、OSのファイルマネージャを開くAPIもありません（Mac/Win共通の制約）。
- **Photoshop のバージョン検出は 2020 以降** — `.psd` / `.psb` / `.pdf`（Photoshop編集機能保持）のバージョンは、Photoshop 2020（バージョン21）以降が記録する内部情報（cinf）から取得します。そのため **Photoshop 2019（CC 2019 / バージョン20）以前**で保存されたファイルは、種類は判定できてもバージョンは表示されません。<br>`.eps`（Photoshop EPS）は別方式のため、この制限はありません。
